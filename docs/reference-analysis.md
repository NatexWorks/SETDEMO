# Seven-reference analysis — NatexWorks portfolio

Research checked: 31 October 2026.

This matrix distinguishes direct browser-readable evidence from archival case studies and inaccessible pages. It does **not** claim that every source experience was replayed in a full interactive browser session. Text-readable page structure was inspected where available; the browser tool could not provide full scroll playback, device-level gesture testing, or complete visual screenshots for every source. Unverified mechanics are marked as such.

## Browser inspection limits

- Orano: the direct source had no readable page lines. Its interaction notes are explicitly from the Immersive Garden case study.
- Corn Revolution: the live page returned an unsupported-browser message. Continuous camera transformation details come from an archival teardown, not a fresh replay.
- Lando Norris: page content and navigation were readable, but device rotation and gesture behaviour were not exhaustively tested.
- 3D Web Lab: the direct page had no readable lines. The CSS Design Awards listing supports its responsive WebGL direction, not specific live interactions.
- Christen Dijoux: the direct fetch failed; no interaction is attributed to it.
- BRAND NW and Gian Media: their text-readable page structures were inspected. This is not a complete visual screenshot audit or timing-accurate scroll recording.
- No source site's implementation framework is assumed from appearance alone.

## Implementation decisions derived from the research

1. Home uses a scroll-progress pinned narrative and a separate lazy-loaded 3D visual.
2. Services uses a brief → interface → system assembly transformation rather than repeating the homepage crossfade.
3. Work uses an editorial horizontal rail on wide screens and touch scrolling on tablet/mobile.
4. Case studies use layered reading panels; these become ordinary flow on small screens.
5. About remains editorial and content-led; not every page needs a spectacle.
6. No reference brand, client, project result, metric, or visual identity is copied.
